# 🎬 UX Laws Dashboard (Netflix-Style)

A cinematic, highly interactive dashboard exploring the 30 psychological laws of User Experience design. Inspired by the Netflix UI, this project serves as a comprehensive, visually engaging directory of UX principles.

## ✨ Features

- **Cinematic UI**: A sleek, dark-mode interface modeled after modern streaming platforms, featuring a dynamic hero section and horizontal scrolling carousels.
- **30 UX Laws**: Complete catalog covering all major UX psychology principles (Fitts's Law, Hick's Law, Law of Prägnanz, etc.).
- **Interactive Sandboxes**: Live, code-driven visual sandboxes where users can manipulate sliders and toggles to see how each law impacts UI elements in real-time.
- **Rich Content Modals**: Deep-dive modals containing:
  - Video lectures (YouTube embeds)
  - Key takeaways & UX implementation tips
  - Real-world case studies (Apple, Google, Netflix, etc.)
- **Dynamic Filtering**: Instantly search for laws or filter by category (Heuristic, Principle, Gestalt, Cognitive Bias).

## 🛠️ Tech Stack

- **Framework**: Vanilla JavaScript (ES6 Modules)
- **Styling**: CSS3 (Custom Properties, Flexbox, CSS Grid)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Icons**: [Feather Icons](https://feathericons.com/)

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YourUsername/ux-laws-dashboard.git
   ```
2. Navigate into the directory:
   ```bash
   cd ux-laws-dashboard
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server:
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000`.

### Building for Production

To create a production-ready build:
```bash
npm run build
```
The optimized files will be generated in the `dist` directory.
